# e2e/docs/

Deep explanations specific to the browser suite, linked from
[`../AGENTS.md`](../AGENTS.md) rather than inlined into it.

**Goes here:** flow-authoring guidance, locator strategy, notes on `agent-browser`
behaviour, how the CI and local harnesses differ.

**Does not go here:** the flow format overview (that is [`../README.md`](../README.md)),
conventions the agent must follow (that is [`../AGENTS.md`](../AGENTS.md)), or debugging
notes (that is [`../INSIGHTS.md`](../INSIGHTS.md)).

**Note:** this package has no docs-spec folder. [`../specs/`](../specs) holds live
`*.flow.json` test scenarios, so proposals for new flows go here in `docs/`, or in
[`../../specs/`](../../specs/README.md) when they span packages.
