# server/specs/

Design specifications for work confined to the API package. Anything spanning packages
belongs in [`../../specs/`](../../specs/README.md).

**Goes here:** what we are about to build in this package and why, alternatives
considered, acceptance criteria.

**Does not go here:** how the API already works (that is [`../docs/`](../docs/README.md)
and [`../README.md`](../README.md)), or post-mortems (that is
[`../INSIGHTS.md`](../INSIGHTS.md)).

Naming: `LNN-topic.md` for course lessons, `NN-topic.md` otherwise.
