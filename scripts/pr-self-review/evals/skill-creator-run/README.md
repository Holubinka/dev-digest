# skill-creator workspace

The raw run data behind `.claude/skills/pr-self-review/eval-fixtures/benchmark.json`/`.md`. This is
skill-creator's own workspace layout (`references/schemas.md`'s `iteration-N/eval-N/{with_skill,
without_skill}/run-N/`), generated by following its real `scripts/aggregate_benchmark.py` and
`eval-viewer/generate_review.py` — not a hand-rolled equivalent.

```
iteration-1/
  eval-0/                        security-route (id 0 in ../../../../.claude/skills/pr-self-review/eval-fixtures/evals.json)
    eval_metadata.json           prompt + assertions for this eval
    with_skill/run-1/
      outputs/report.md          the actual pr-self-review report from that run
      grading.json               per agents/grader.md: expectations graded with evidence
      timing.json                real captured tokens + duration_ms from the task notification
    without_skill/run-1/         same shape, for the no-skill baseline
  eval-1/                        onion-notify-service
  eval-2/                        frontend-label-filter
  benchmark.json / .md           python -m scripts.aggregate_benchmark's output — copied up into
                                  the skill's evals/ folder as the published scorecard
```

**1 run per configuration, not 3.** A real `/pr-self-review --full` run costs ~10-12 minutes and
~100-150k tokens (top-level agent only — it dispatches further subagents whose own spend isn't
counted here), so this workspace was not repeated to measure variance. `benchmark.md`'s `± stddev`
columns read 0 for `with_skill` accordingly.

**Grading was done directly, not via a dispatched grader subagent.** The `with_skill`/`without_skill`
outputs already came from real runs whose findings were independently cross-checked (see `grade.sh`
in the parent folder), so re-deriving already-certain facts through a fresh subagent would have
spent real tokens for zero new information. Grading followed `agents/grader.md`'s rubric exactly —
evidence quoted per expectation, claims extracted and verified, an eval-critique step included —
just executed directly against known-true data instead of blind.

To regenerate `benchmark.json`/`.md` from this workspace, or to extend it with a new eval, see
`../../../../.claude/skills/pr-self-review/eval-fixtures/README.md`'s "Refreshing the scorecard" section.
